Ringkasan Kompleksitas Algoritma

  1. Jaringan jalan direpresentasikan sebagai graf berbobot G = (V, E, w).
  2. Relaksasi Dijkstra: d[v] = min(d[v], d[u] + w(u, v)).
  3. Time Complexity: O((V + E) log V) dengan Min-Heap Priority Queue, atau O(V²) dengan Array Linear Scan.
  4. Space Complexity: O(V + E) menggunakan struktur Adjacency List.
